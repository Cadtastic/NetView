Roku ECP Cheat Sheet

The External Control Protocol is the HTTP API every Roku device and Roku TV exposes on the local network. Reads use GET. Anything that changes the TV uses POST. Set your TV's address below and every command on the page updates to match.

Commands return 403 Forbidden? The TV's Network access setting is probably on Limited, which allows a few reads and refuses every POST. Change it on the TV:
Settings → System → Advanced system settings → Control by mobile apps → Network access → Default

Network access settings
Set on the TV under Settings → System → Advanced system settings → Control by mobile apps → Network access. There is no token or pairing; this setting is the only access control.

What the responses mean

      

        
200Done. Commands return an empty body, so success looks like nothing happened in the terminal.

        
403Refused by the Network access setting. Limited or Disabled mode, or the request came from outside the private LAN while on Default.

        
404Wrong method or unknown path. Usually a GET sent to a POST endpoint, such as typing a keypress URL into a browser. Also an unknown app ID.

        
noneTimeout or connection refused. ECP is Disabled, the TV changed IP address, or it is fully powered down rather than in standby.

      

    


    

      
Finding Rokus on the network
Rokus answer SSDP searches for roku:ecp. Each reply carries a LOCATION: http://<ip>:8060/ header. The Find TVs script sends this search and checks port 8060 on every address in your subnet at the same time. Give the TVs a DHCP reservation so their addresses stay put.
